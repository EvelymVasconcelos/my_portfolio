02 — Sobre

Engenheira de software backend, pesquisadora e Python há mais de 6 anos.

Sou formada em Sistemas de Informação pela UFAM e construo backend no ecossistema Python: APIs RESTful com FastAPI e Django, em microsserviços com Docker e Kubernetes, integrando PostgreSQL e bancos NoSQL.

Hoje sou engenheira de software backend no Sidia, onde lidero a criação de APIs REST de alta performance para produtos globais. Antes, na Bemol Digital, estruturei processos de ETL e otimizei consultas SQL em sistemas de alta disponibilidade para o varejo.

Levo o mesmo rigor para a pesquisa: sou autora principal de artigos sobre automação de testes e CI/CD apresentados no IEEE SEAI 2024 e no ICSCA 2026.
